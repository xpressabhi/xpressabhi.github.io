# Contributing

Thanks for taking an interest in this portfolio repo! It's a personal
website, so feature PRs are rare — but bug reports, typo fixes, and
accessibility improvements are very welcome.

## Making changes

1. Edit `index.html` — it's the entire site (no build step).
2. Open `index.html` in a browser to verify your change (or serve the
   repo root with any static server, e.g. `python3 -m http.server`).
3. Open a PR with a short description of the change and why it helps.
