# Security Policy

## Reporting a Vulnerability

This is a personal portfolio site with no user data or payment handling.
Still, if you find a security issue, please report it privately instead of
opening a public issue:

- Email: **akm.nitt@gmail.com**
- Subject prefix: `[SECURITY]`

You can expect an acknowledgment within 7 days. Please include the affected
URL, a description of the issue, and reproduction steps if possible.
